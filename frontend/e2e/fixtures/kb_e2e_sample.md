# E2E 知识库样例文档

## 产品概述

TestAI Community 知识库模块用于文档入库与 RAG 问答。
本文档仅供自动化 E2E 测试使用，包含足够长度的段落以便清洗切分。

## 功能要点

1. 用户登录后进入知识库 Hub。
2. 在「清洗入库」上传文档并等待处理完成。
3. 审核员在审核页点击「批准入库」。
4. 入库完成后可在「知识问答」基于文档内容提问。

## 验收标准

- 清洗任务状态最终达到 pending_review 或 approved。
- 问答回答应引用本文档中的「功能要点」或「产品概述」。
- 参考来源中应出现本文件名。

## 补充说明

清洗流水线可能依赖本机 Ollama 向量模型与外部 LLM。
若环境未就绪，E2E 会记录流水线依赖问题，而不是误判为前端 UI 故障。
