# 需求文档：62 定时任务管理平台

## 1. 背景

62 服务器负责调度绿区定时任务（算法版本监测、TestAI 日/周报触发、调度心跳诊断），每次任务结束后通过钉钉机器人把运行报告发到运维群。

## 2. 目标

- 按 cron 调度 `tasks/` 下已注册任务，记录每次运行状态与事件。
- 任务结束（成功或失败）向钉钉群发送「运行报告」。
- 任务代码可独立更新（`tasks/` 目录与 exe 分离），不必每次改业务都重打全部平台代码。
- frozen exe 内必须包含动态任务所需的第三方库，避免任务在 import 阶段 0 秒失败。

## 3. 本次修复需求（2026-08-27）

**现象：** 钉钉运行报告「算法版本监测」失败，耗时 0s，摘要为 `ModuleNotFoundError: No module named 'httpx'`。

**需求：**

1. 打包后的 `deploy-task-manager.exe` 必须包含 `httpx`、`boto3`、`botocore`、`dotenv`。
2. 打包脚本不得删除已维护的 spec、不得现场生成丢失 hiddenimport 的 spec。
3. 修复不得改变调度、Webhook 发群、其它任务的业务逻辑。

## 4. 非目标

- 不改算法监测本身的采集/写钉钉文档逻辑。
- 不改日/周报调用 64 的逻辑。
- 不把业务日报发到运维群（业务发群仍在 64）。
