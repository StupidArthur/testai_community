# 项目管理 · 补测 Checklist

> 文档版本：2026-08-10  
> 用途：实习生在「工作台基础 CRUD」之外的补测清单  
> 产品规则依据：[test_manage_product_guide.md](./test_manage_product_guide.md)  
> 建议账号：`manager / 123456`（管理员）；另备 Engineer（lead / owner）各一

**使用说明**

- 勾选 `[ ]` → `[x]`；阻塞记到「问题记录」
- 优先级：P0 必须过；P1 本轮尽量过；P2 有时间再测
- 数据建议统一前缀，如 `【补测】`，测完可归档/删除项目

---

## 0. 前置准备

| # | 项 | 结果 |
| --- | --- | --- |
| 0.1 | 准备管理员、Task lead、Action owner（非 lead）、无关工程师 至少各 1 个账号 | [ ] |
| 0.2 | 建测试项目 + 领域 + 若干 Task（含 lead / 测试人员） | [ ] |
| 0.3 | 记录当前「本周结束」时刻与周报预计发送时刻 | [ ] |

## P0 · 必须过

### A. 本周大屏

| # | 检查点 | 期望 | 结果 |
| --- | --- | --- | --- |
| A1 | 进入「本周大屏」默认视图 | 有 KPI（Task 数 / 有风险 / Action 数 / 均进度）、明细、风险侧栏 | [ ] |
| A2 | 明细 Tab「需关注」 | 含：有开放风险，或仍有进行中 Action；纯草稿不算 | [ ] |
| A3 | 明细 Tab「全部」 | 当前筛选下全部 Task | [ ] |
| A4 | 明细 Tab「已完成」 | **仅** Task 自身状态=已完成；Action 全做完不会自动进来 | [ ] |
| A5 | 草稿 Action | 大屏不展示；仅草稿的 Task 整行隐藏；工作台仍可见 | [ ] |
| A6 | 本周 0 Action 的空 Task | 大屏仍显示（催建） | [ ] |
| A7 | Task 进度列 | 有手填用手工；未手填显示 Action 平均 +「未手填」提示 | [ ] |
| A8 | 全屏汇报 | 可进入/退出全屏，内容可读 | [ ] |
| A9 | 风险侧栏 | 仅开放风险（进行中且最新风险非空） | [ ] |

### B. 我的 Action

| # | 检查点 | 期望 | 结果 |
| --- | --- | --- | --- |
| B1 | 列表范围 | 仅当前周 + owner=当前用户 | [ ] |
| B2 | 非本人 Action | 不出现在「我的 Action」 | [ ] |
| B3 | 写日更 → 标记完成 | 可走通主路径 | [ ] |

### C. Action 日更（核心闭环）

| # | 检查点 | 期望 | 结果 |
| --- | --- | --- | --- |
| C1 | 进行中 + owner 写日更 | 进度 % 必填；说明去空白后非空 | [ ] |
| C2 | 进度倒退 | 低于当前进度 → 拒绝 | [ ] |
| C3 | 填风险 / 阻塞 | 最新非空 → 计为开放风险（大屏/推送可见） | [ ] |
| C4 | 风险解除 | 日更把风险栏留空保存 → 开放风险消失 | [ ] |
| C5 | 同天多次日更 | 每天一条，后写覆盖 | [ ] |
| C6 | 补历史日更 | 不可补历史日期 | [ ] |
| C7 | 19:50 后写今日日更 | 锁定，不可再改今日日更 | [ ] |
| C8 | 非 owner 写他人日更 | 拒绝（管理员除外；lead 若非 owner 也不能代写） | [ ] |
| C9 | 草稿 / 已完成写日更 | 不可 | [ ] |

### D. Action 状态机

| # | 检查点 | 期望 | 结果 |
| --- | --- | --- | --- |
| D1 | 草稿可改字段 | 标题/负责人/内容/环境可改 | [ ] |
| D2 | 草稿 → 发布 | 成功；字段锁定 | [ ] |
| D3 | 发布后改字段 / 改派 | 不可；须用更正说明 | [ ] |
| D4 | 进度未满 100% 点完成 | 按钮禁用或拒绝 | [ ] |
| D5 | 日更到 100% → 完成 | 成功；终态 | [ ] |
| D6 | 完成后重开 / 再日更 | 不可 | [ ] |
| D7 | 取消 Action | 不支持 | [ ] |
| D8 | 更正说明 | 进行中/已完成可追加；只追加时间线，不改原字段 | [ ] |

### E. 权限矩阵（抽测）

| # | 操作 | 管理员 | lead | owner（非 lead） | 其他 | 结果 |
| --- | --- | --- | --- | --- | --- | --- |
| E1 | 建项目 / 领域 / Task | ✅ | ❌ | ❌ | ❌ | [ ] |
| E2 | 编辑 Task / 改 Task 状态 / 填 Task 周进度 | ✅ | ✅ | ❌ | ❌ | [ ] |
| E3 | 设本周结束 | ✅ | ❌ | ❌ | ❌ | [ ] |
| E4 | 建/复制本周 Action、改草稿 | ✅ | ✅ | ❌ | ❌ | [ ] |
| E5 | 发布 / 完成自己的 Action | ✅ | ✅（本 Task） | ✅（自己的） | ❌ | [ ] |
| E6 | 写日更 | ✅ | 仅自己是 owner | ✅ | ❌ | [ ] |
| E7 | 手动推送（日报/周报） | ✅ | ❌ | ❌ | ❌ | [ ] |
| E8 | 无关工程师 | 可看有本周 Action 的看板；无编辑权 | | | | [ ] |

## P1 · 本轮尽量过

### F. 周切换 / 历史周 / 切周

| # | 检查点 | 期望 | 结果 |
| --- | --- | --- | --- |
| F1 | 本周 / 历史切换 | 大屏与工作台共用；历史最多 10 周 | [ ] |
| F2 | 历史周只读 | 不可新建 / 日更 / 改状态；无新建入口 | [ ] |
| F3 | 管理员改「本周结束」 | 须晚于现在与本周起点；本周 Action 截止同步；界面显示周报发送时刻（结束+15 分钟） | [ ] |
| F4 | 切周后空 Task | 工作台标红提醒；可新建或复制上周 | [ ] |
| F5 | 复制上周 Action | 挂当前周；**不带上周风险** | [ ] |
| F6 | 一键复制全部（若有） | 仅有权限者可用；结果符合 F5 | [ ] |
| F7 | 切周日日更归属 | 切周当天全天日更仍写旧汇报周；新周日更从次日起 | [ ] |

### G. Task 周进度与状态

| # | 检查点 | 期望 | 结果 |
| --- | --- | --- | --- |
| G1 | Task 抽屉填本周进度 | 管理员 / lead 可填；供大屏/周报 | [ ] |
| G2 | 未手填 | 大屏/周报用 Action 平均 +「未手填」提示 | [ ] |
| G3 | Task → 已完成 | 不可再加本周 Action | [ ] |
| G4 | Action 全完成但 Task 仍进行中 | 「已完成」Tab 仍不出现该 Task | [ ] |

### H. 项目归档 / 删除

| # | 检查点 | 期望 | 结果 |
| --- | --- | --- | --- |
| H1 | 归档项目 | 仅管理员；列表隐藏 | [ ] |
| H2 | 永久删除项目 | 仅管理员；下属数据一并清理 | [ ] |
| H3 | 非管理员归档/删除 | 无入口或拒绝 | [ ] |

### I. 钉钉推送

| # | 检查点 | 期望 | 结果 |
| --- | --- | --- | --- |
| I1 | 日报 dry_run | 管理员可预览；Action 视角（今日进展 + 开放风险）；无风险也有内容 | [ ] |
| I2 | 周报 dry_run | 管理员可预览；本周大屏截图形态（短文 + 链接 + screenshot_bytes）；无风险也发 | [ ] |
| I3 | 草稿风险 | 不计开放风险 / 不进日报口径 | [ ] |
| I4 | 本周 0 Action 的空 Task | 不计入推送 KPI 的 task_count（看板仍可标红） | [ ] |
| I5 | 幂等（同日/同周再触发） | 默认不重复真发（可用 force 调试） | [ ] |
| I6 | 真发（可选，需 webhook） | 群内收到 1 条；超长不拆条 | [ ] |

## 角色一周路径（冒烟）

按角色各走一遍，全部通过再标 `[x]`。

| 角色 | 路径 | 结果 |
| --- | --- | --- |
| 管理员 | 建项目→领域→Task → 配/核对周结束 → dry_run 推送 → 必要时代写日更 | [ ] |
| Task lead | 切周后新建/复制 Action → 填内容 → 发布 → 盯大屏 → 填 Task 周进度 → Task 收尾改状态 | [ ] |
| Action owner | 「我的 Action」日更（19:50 前）→ 进度 100% → 标记完成 | [ ] |
