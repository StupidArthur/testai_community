# 需求进展功能说明

> 新增能力：在 Task 上区分「整需求生命周期」与「测试任务状态」；大屏增加 **需求总览** 视图。  
> 日期：2026-08-20

---

## 1. 两个字段分别是什么

| 字段 | 含义 | 谁改 |
|------|------|------|
| **需求进展** | 需求从开发到测完的阶段 | **Admin / Manager** |
| **测试状态**（原 Task 状态） | 测试侧进行中 / 已完成 / 归档 | lead + Admin / Manager；**仅「测试中 / 测试完成」可改** |

---

## 2. 需求进展阶段与时间

```text
待开发 → 开发中 → 待提测 → 待测试 → 测试中 → 测试完成
```

| 阶段 | 关联时间（可**待定**/留空） | 可否建 Action | 是否显示测试状态 |
|------|------------------------------|---------------|------------------|
| 待开发 | — | 否 | 否 |
| 开发中 | — | 否 | 否 |
| 待提测 | 预计提测时间 | 否 | 否 |
| 待测试 | 实际提测时间 | 否 | 否 |
| 测试中 | 测试开始；预计结束 | **是** | **是** |
| 测试完成 | 测试结束 | 否 | 是（只读完成） |

说明：

- 各阶段关联时间可**待定**（留空）；大屏摘要显示「待定」。  
- **待测试**：已提测但测试暂无资源，与「测试中」分开。  
- **开发中 / 待提测不合并**：待提测专责预计提测时间与交测排队。  
- 进入「测试中」会同步测试状态为进行中；进入「测试完成」同步为已完成。

---

## 3. 工作台

- Task **操作 → 进度**：上半 **需求进展（流程+时间）**，下半 **本周测试进度**。  
  - Admin/Manager 在此改阶段与关联时间（可待定）。  
  - **仅「测试中」**可填本周进度（前后端均拦截）；非测试中会提示锁定。  
- Task **操作 → 详情**：标题 / 需求 / 负责人等；只读展示当前需求进展（改流程去「进度」）。  
- lead：可看流程、在测试中改测试状态与周进度；**不能**改需求进展。  
- **仅测试中** 显示「+ Action」。

---

## 4. 大屏

| 视图 | 用途 |
|------|------|
| 今日 | Action 执行（默认仍看阻塞 / 未日更） |
| 本周 | 测试周报；「需关注」默认盯 **待测试 + 测试中** |
| 历史 | 读该周 **需求进展快照**（切周时固化） |
| **需求总览** | 六阶段漏斗 KPI；**默认展示全部阶段**；列表按进展排序：**测试中 → 待测试 → 待提测 → 测试完成 → 开发中 → 待开发**；列仅 Task / 领域 / 需求进展 / 负责人；点 KPI 可筛单阶段 |

公开深链：`/tm-screen?view=pipeline`（或 `view=req`）。

本周/历史筛选顺序含：**需求进展**（靠前）、**测试状态**、……、**Action 状态**（靠后）。  
需求总览筛选仅：**需求进展** · 域 · Task 负责人（不重复展示测试状态；列表不展开 Action）。

---

## 5. 历史周快照

切周开新窗时，系统把各 Task 当前需求进展与时间字段写入 `tm_task_stage_snapshots`。  
历史大屏展示该周快照，不读「现在」的阶段。

---

## 6. 存量数据

升级后：

- 原「进行中」Task → 需求进展 **测试中**  
- 原「已完成」Task → 需求进展 **测试完成**  
- 新建 Task 默认 **待开发**

---

## 7. 使用建议（一周）

1. Manager 按研发节奏推进：待开发 → 开发中 → 待提测（填预计提测）→ 待测试（填实际提测）。  
2. 有测试人力后改为 **测试中**（填开始时间）→ lead 建 Action、日更。  
3. 测完由 Manager 改为 **测试完成**（填结束时间）。  
4. 领导看「本周」盯测试堵点；看「需求总览」盯整条需求卡在开发还是等人测。

---

## 8. 演示灌数

```text
cd backend
python scripts/seed_tpt_realistic_board.py
```

重建 **TPT v2.1** 约 20 个 Task：待开发 2 / 开发中 3 / 待提测 3 / 待测试 3 / 测试中 6 / 测试完成 3。  
「测试中」另含跨周延续、阻塞、未日更、空卡、仅草稿等场景。
