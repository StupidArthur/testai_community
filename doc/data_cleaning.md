# 数据清洗（知识入库前质检）

> 版本：2026-06-17  
> 模块路径：`backend/app/data_cleaning/`、`frontend/src/data_cleaning/`

---

## 功能简介

**数据清洗**是知识库的上游环节：在上传长文档进入向量检索之前，先完成 **提炼精华 → 锚点对齐 → 库内冲突检测 → 人工确认 → 写入知识库**。

解决三类问题：

1. **文档太长太杂**（PRD 合集、性能报告含大量原始数据）— 只把可检索精华入库  
2. **多源不一致** — 自动对比库内已有知识，提示逻辑冲突或版本更新  
3. **误入库** — 必须人工「批准入库」，不自动写入 Chroma

---

## 使用流程

### 1. 新建清洗任务

导航：**数据清洗** → **新建清洗任务**

上传时只需填写：

| 字段 | 说明 |
|------|------|
| 目标知识库 | 批准后写入哪个库 |
| 文档类型 | PRD / 性能报告 / 混合 / 通用 |
| 产品、版本、环境 | 可选，用于 scope 与冲突判断 |
| 文件 | md、txt、docx、pdf 等（与知识库格式一致） |

**不需要**为整份大文档手工选择几十个功能锚点。

### 2. 自动处理（后台）

系统会：

1. 保存原始文件到 `data/knowledge_base/clean/{kb_id}/{job_id}/raw/`  
2. 解析文档并按标题切分为 **段落单元**  
3. 对每段 LLM **提炼精华**（去掉大段测试数据噪声）  
4. **匹配锚点词典**（同义词 + 向量）  
5. **召回库内相似 chunk** 并精判：重复 / 版本更新 / 环境差异 / 逻辑冲突  
6. 任务状态变为 `pending_review`

### 3. 人工审核

打开任务详情，逐段检查：

- **精华正文**：可编辑  
- **锚点**：可修改（多选）  
- **库内对比**：查看冲突说明与旧资料片段  
- **操作**：新增入库 / 替换旧知识 / 并存 / 跳过  

存在 **逻辑冲突** 的段落，必须明确选择操作后才能「批准入库」。

### 4. 批准入库

点击 **批准入库** 后：

- 每条批准的段落生成 **Knowledge Unit（知识单元）**  
- 写入 Chroma 向量库（`ku_status=active`）  
- 若选择「替换」，旧 KU 标记 `superseded` 并从检索中排除  
- 原始文件在知识库文档表登记为 `archived`（仅溯源，不参与检索）

### 5. 知识库问答

在目标知识库中正常 RAG 对话；检索优先使用 **active** 状态的知识单元。

## 锚点词典

- 路径：**数据清洗** → **锚点词典**（仅 Admin 可新建）  
- 启动时自动种子：登录、登录-短信验证码、订单、接口等  
- 建议 Admin 维护产品 **功能树 + 同义词**；LLM 提炼时自动匹配  
- 匹配不上的锚点可在审核页手工选择

---

## 文档类型策略

| 类型 | 提炼重点 | 原始数据 |
|------|----------|----------|
| PRD / 需求 | 功能规则、流程、接口、约束 | raw 归档，不进向量库 |
| 性能报告 | 结论、瓶颈、关键指标表 | 海量明细不进向量库；P3 再做附录检索 |
| 混合 / 通用 | 按章节提炼 | 同上 |

---

## 冲突处理规则

| 检测结果 | 含义 | 默认建议 |
|----------|------|----------|
| contradiction | 同版本/环境下矛盾 | 必须人工选择操作 |
| update | 新版本覆盖旧规则 | 替换（supersede） |
| scoped_difference | 不同环境/版本可并存 | 并存 |
| same_fact | 内容重复 | 跳过 |
| unrelated | 不相关 | 忽略 |

## 数据存储

| 数据 | 位置 |
|------|------|
| 任务、段落、锚点、KU 元数据 | SQLite（`dc_*` 表） |
| 原始上传文件 | `data/knowledge_base/clean/.../raw/` |
| 向量 | `data/knowledge_base/chroma/` |

开发与生产环境应使用 **各自的** `DATABASE_URL` 与 `KNOWLEDGE_BASE_DATA_DIR`（参见 `doc/deploy_ab_same_pc.md`）。

---

## 与「直接上传知识库」的关系

- **推荐**：长文档、多来源材料 → 先走数据清洗  
- 知识库详情页仍保留直接上传（适合已整理好短文）  
- 清洗批准后的知识与直接上传的文档 **在同一知识库** 中共存检索

---

## 限制（当前版本）

- 单任务最多处理约 **120** 个段落（控制 LLM 成本）  
- 过短段落（&lt;120 字）自动跳过  
- 精判依赖 MiniMax；Embedding 依赖本机 Ollama（bge-m3）  
- 性能报告 Excel 大表 **P0/P1 仅归档**，不做附录关键词检索  

环境准备与需提供项见 **[knowledge_and_cleaning_setup.md](./knowledge_and_cleaning_setup.md)**。
